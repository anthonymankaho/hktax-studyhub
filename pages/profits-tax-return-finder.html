Profits Tax Return — Box Finder

Search BIR51 (corporations), BIR52 (persons other than corporations), and BIR54 (non-resident persons) by keyword to find which box a figure or disclosure goes in. This is a lookup aid over the current (4/2025) forms — not a tax calculator; it does not compute figures for you.

How to use Type a keyword (e.g. "depreciation", "two-tiered", "loss brought forward", "audited accounts", "MPF", "non-resident"). Filter by form if you already know which return you're working on. Where a box ties to a concept covered elsewhere in the hub, a "View section" link is shown.

Scope & limits Box numbers and labels are drawn from the current forms as published on ird.gov.hk (revision 4/2025) — verify against a freshly downloaded form before relying on a box number for an actual filing, since IRD periodically renumbers when new disclosure items are added. This tool does not replace the "tax computation with supporting schedules" you must prepare and attach separately — Part 1's boxes 1–3 are only the final results of that computation, not the computation itself.
